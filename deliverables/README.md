# Helm 演示视频

本目录存放 Helm（tChrome Chrome 扩展）的演示视频，便于通过 GitHub 链接分享。

## hanoi-10-discs-8x.mp4

10 盘汉诺塔（1023 步最优解）完整通关实录的 8 倍速版本。

- 规格：h264 / 1920×1080 / 30fps / 2030 帧 / 67.67 秒 / 5.3 MB
- 内容：左侧 TowerOfHanoiOnline.com 游戏画面，右侧 560px 的 Helm 侧栏真实会话输出；
  全程真实鼠标点击逐步求解，中途不剪辑、不加转场，仅整体 8× 加速
  （原始速率为 30fps / 541.33 秒 / 16240 帧，保留在本地，未入库）
- 结尾画面为站点自带结果浮层：Moves 1,023、Efficiency 100%
- 封面：hanoi-10-discs-8x-poster.jpg

## helm-intro.mp4

Helm 的功能介绍片（benchmark 版），含产品定位、规模指标、工具分层、
10 盘汉诺塔 benchmark、架构与收尾等段落，并用一段 2048 两轮策略对比
（随机走法 1236 分 vs 角落优先 2620 分）演示「先想、再做、复盘、改进」的过程。

- 规格：h264 / 1920×1080 / 30fps / 2753 帧 / 91.77 秒 / 8.4 MB
- 封面：helm-intro-poster.jpg

## 关于侧栏画面

Chrome 的 `chrome-extension://` 页面拒绝被截图/录屏，因此视频右侧的侧栏是
`http://127.0.0.1:8901/__stage` 的同源镜像页：它加载 `dist/` 里的真实侧栏页面、
反代本机 18789 服务的真实接口，喂进去的是真实会话数据，但页面地址不是扩展面板本身。
