# 图片存储与模型输入

截图工具返回的 PNG/JPEG data URL 经 runtime 处理后，二进制保存到会话目录 `images/<sha256>.png|jpg`，相同图片去重。单张最多20 MiB；工具返回、toolIO、事件、归档和 provider.md 仅保存 id、相对路径、格式、尺寸及字节数。

每次模型请求从本轮未归档工具记录中选取最近最多4张不同图片。ChatMessage.images 携带引用，Provider 在发送 HTTP 请求时读取并校验文件，构造 user content 中的 text 与 image_url；Base64 只出现在发送给模型的请求中。provider.md 单独记录图片引用，不记录请求里的编码。文本上下文字符阈值不计图片的模型 token 用量。

此链路支持工具截图供模型观察；不提供侧栏上传、粘贴图片的入口。实际视觉能力由上游模型和网关决定。旧日志中已存在的截图编码不自动重写；新截图使用此机制。删除会话会删除其图片文件，其他会话不能借引用读取它。
