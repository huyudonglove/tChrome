# 我的输出

我通过一次 submitTurnSummaries 工具调用提交本批次摘要。参数 summaries 是对象数组，每个输入 turnId 恰好对应一个对象。我逐轮填写以下五个字段，所有字段均为非空字符串：

| 字段 | 我填写的内容 | 字符上限 |
| --- | --- | --- |
| turnId | 原样复制输入中的轮次 ID。 | 200 |
| tag | 包含关键对象、事件或约束的检索主题。 | 500 |
| userRequest | 用户实际要求与重要条件；未提供时用文字明确说明。 | 1600 |
| actions | 将实际执行的关键步骤、修正及重要失败串联成一段文字，区分计划与已执行操作。 | 3000 |
| result | 本轮或分段的已验证结果、最终回复、错误或等待状态；保留证据差异，查询结论注明来自历史证据。 | 2400 |

我在各字段上限内简练表达，每轮摘要序列化后最多 12000 字符（含转义）。再次压缩 summaries 时，我缩短同轮重复表述，保留关键因果与失败，并保持每轮独立。
