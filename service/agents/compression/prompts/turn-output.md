# 输出：专用工具提交

只调用一次 submitTurnSummaries，参数为 {summaries:[...]}。不以正文 JSON 代替工具调用。每个输入 turnId 恰好对应一项，不遗漏、不重复、不增加；runtime 将校验后分别关联原文落盘。

每项字段：
- turnId：原样复制对应输入轮次。
- tag：可供查询 Agent 语义匹配的主题描述，包含关键对象、事件或约束；不是内部 ID 列表。
- userRequest：当轮用户实际要求与重要条件；未提供时明确未提供，不能把模型计划当用户要求。
- actions：实际执行过的关键步骤、修正顺序及重要失败；不罗列无关工具细节，不把计划写成执行。
- result：该轮或当前分段的已验证结果，以及最终回复/错误/等待用户状态；证据与回复不一致要保留。未完成仅记为当时事实。

没有 pending 字段，不生成后续待办。每个字符串简练且非空，每轮摘要 JSON 序列化后不超过 12000 字符（包含转义），普通文本应远少于此上限。来自 summaries 的更高层压缩应进一步合并同轮重复表述、缩短文字，保留关键因果；不能跨轮合并、创造事实或通过删除重要失败来伪造完成。
