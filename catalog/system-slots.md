# System 插槽清单

本文件维护 system 插槽的功能与装配顺序。新增、删除、重命名或调整 system 插槽职责、顺序时，同步更新本文件、对应插槽文件、窗口模板和装配测试。

当前状态：已完成独立文件装配；实际顺序与下表一致。每槽文件位于 `catalog/slots/system/<name>.md`，包含用途、来源、边界与 `{{data}}` 数据占位；静态 system 规则无附加数据。

| 顺序 | 插槽 | 功能 |
| --- | --- | --- |
| 1 | `#identity` | 定义 Agent 的身份、职责范围、语言与沟通风格。 |
| 2 | `#environment` | 说明运行环境，以及模型、本机服务、Chrome 扩展的职责。 |
| 3 | `#execution` | 定义任务推进、结果判断、错误处理、授权、等待用户与结束任务的通用执行规则。 |
| 4 | `#output` | 定义过程说明、最终答复和追问的表达格式。 |
| 5 | `#baseTools` | 提供常驻基础工具的用途、参数、返回与状态变化；内容由统一工具目录生成。 |

## 管理边界

- 本清单负责导航和职责定义，窗口模板按清单顺序装配。
- 每个插槽的具体内容由其独立文件维护。
- 工具用法由工具目录维护，基础工具装入 `#baseTools`；动态工具装入 user 的 `#tools`。
- user 插槽清单单独维护在 [user-slots.md](user-slots.md)。

维护要求：增删、重命名或调整职责与顺序时，同步修改本清单、独立槽文件、窗口模板、装配测试与 docs/examples 窗口快照。工具说明唯一来源是 `catalog/tools/*.json` 的 `function.description`；index 只做目录分类，不维护用途或参数手册。
