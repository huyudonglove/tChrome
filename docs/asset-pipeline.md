# 资产入窗与归档（设计草案）

状态：草案，待确认。只定边界与命名，不描述未实现行为。

## 要解决什么

采集来源变多后（截图、工具超长返回、DOM、stream、下载），曾经各自为政：有的整包进模型窗口，有的只丢本地路径。结果是——高清图可能一次打进上下文，归档只有裸路径，模型无法按 id 回取细节。

收成一条流水线、三个位置：

```text
采集 → 入窗门禁 → 归档 L1 / L2
         ↓
    模型窗口（只看门禁输出）
         ↓
    按 id 回取（search / 取块 / 裁切）
```

## 术语

| 名 | 含义 |
|---|---|
| 资产（asset） | 一次采集留下的可引用对象（截图、正文档、二进制、DOM 快照） |
| 入窗（admit） | 决定该资产以什么形态进入模型窗口 |
| 归档（archive） | 落盘保存；分 L1 目录与 L2 正文 |
| 投影（project） | 按类型生成入窗形态（缩略图、预览文、元数据） |

## 归档两层

### L1 目录（决策层）

每条资产一行，进窗口或可 list：

| 字段 | 说明 |
|---|---|
| `assetId` | 短前缀 + 持久自增（沿用现有 ID 规则） |
| `name` | 人可读名称（如 `capture_page#page_12`） |
| `kind` | `image` \| `text` \| `binary` \| `dom` \| … |
| `bytes` | L2 正文字节数 |
| `summary` | 一行概述（见「L1 摘要」），供模型判断要不要取 |
| `createdAt` | ISO 时间 |
| `source` | 来源调用：`callId` / 工具名 |

### L2 正文（证据层）

- 图片：**无损原件**为真源（可复现取证）；另存派生图（缩略、分块）只作取用加速，不替代原件。
- 文本：完整原文；超量时已有 externalized 落盘路径并入 L2，L1.summary 用首段或摘要。
- 二进制：原样字节。

L2 不进模型窗口，只按 `assetId` 读。

## L1 摘要（默认实现）

采集时**规则生成**，不额外打模型；一行以内，目标是「值不值得取」，不要求复述全文。

| kind | 默认规则 |
|---|---|
| `text` | 第一个非空标题行（若像标题：短且非句末标点收尾）+ 第一句完整句（按 `。！？!?；;\n` 断句；跳过空行与纯符号行）。无标题则只取首句。 |
| `dom` / 结构 JSON | 顶层键列表 + 主要数组的条数，如 `keys=html,scripts; tables×2` |
| `image` | 来源事实串，不写像素描述：`{宽}×{高} {mode}` + 来源（tab 标题 / URL host / `e_` 角色与 name / 工具名），如 `1280×800 viewport · 记录列表 · list.example.com` |
| `binary` | `bytes` + 来源工具名 + 可知的 content-type / 文件名 |

可选升级（非默认）：对少量关键资产再调一次视觉/文本模型写摘要，写回同一 `summary` 字段；不阻塞采集主路径。

## 入窗门禁（循环协议，核心）

对「即将进入模型窗口」的载荷统一判定；**取回结果再过同一门禁**，不通过就继续降级：

```text
载荷 → 门禁
  ├─ 通过 → 直接入窗
  └─ 不通过 → 降级：摘要 或 压缩图
        入窗时附取用提示（要细节请更精准：矩形/关键字/行窗）
        模型调用工具取 → 结果再过门禁 → 仍大则再降级 → …
```

| 档 | 条件（示意） | 模型看到 |
|---|---|---|
| `inline` | 小于 inline 阈值 | 原文或原图 |
| `preview` | 小于 preview 阈值 | 摘要 / 压缩图 + 取用提示 |
| `ref` | 更大 | 仅 L1 行（含 summary）+ 取用提示 |

要点：

1. **门禁只管形态，不管存不存**——一律先归档 L1/L2，再决定入窗档位。
2. **同批策略不变**——仍只附带本批新资产；历史只保留 L1/路径。
3. **降级必带提示**——preview/ref 不是终点，文案说明信息被压缩/摘过，需要就用更具体的参数再取。
4. **投影按类型**，门禁本身通用：`image` 给压缩图（限最长边）+ 矩形取用；`text` 给 summary + preview 字符窗；`binary` 给元数据 + 路径。

## 大图取用（image 专属）

超过 preview 阈值的图用**坐标取用**，不预切网格：

1. 保存无损原件（L2）
2. 入窗给压缩图（限最长边）+ 尺寸 + 取用提示
3. 模型要细节时传矩形（`assetId` + `x,y,w,h`）或现场 `capture_page(mode=element)`
4. 裁切结果**再过门禁**，仍大则继续压缩或只要更小矩形

网格预切仅作以后的缓存优化，不是主协议。

## 来源如何接入

| 来源 | 归档 | 入窗默认 |
|---|---|---|
| `capture_page` | L1+L2（无损图） | 小图 inline；大图总览+块表 |
| 工具超长返回 | 已有 externalized → 记入 L2 | ref + summary（现有 preview 形态） |
| `stream.pull` / 下载 | L1+L2 | 只 L1（模型显式要看再取） |
| DOM 快照 | L1+L2 | ref；需要结构时 search/读片段 |

## 取用约定

- 列表：按 L1 过滤（kind / name / 时间）
- 读文：`evidence.search`（已存在）或后续统一 `asset.read`
- 读图：取块 / 元素裁切 / 指定 `assetId` 的派生缩略
- 取用结果**再过一遍门禁**，避免二次打穿窗口
